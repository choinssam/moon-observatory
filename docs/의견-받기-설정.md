# 의견을 내 구글 스프레드시트에 쌓기

'의견 보내기'로 들어온 글을 **선생님 구글 계정의 스프레드시트**에 자동으로 쌓는 방법입니다.
다른 회사 서비스에 가입할 필요가 없고, 자료는 전부 선생님 것입니다. **3분이면 됩니다.**

---

## 1. 스프레드시트 만들기

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만듭니다.
2. 이름을 **달 관찰소 의견** 정도로 바꿉니다.

## 2. 스크립트 붙여넣기

1. 위 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 편집기에 있던 내용을 **모두 지우고**, 아래를 그대로 붙여넣습니다.

```javascript
/** 달 관찰소 의견 받기 */
const SHEET = '의견'
const NOTIFY = ''   // 새 의견이 올 때 메일로 알림받으려면 여기에 메일 주소를 넣으세요

function doPost(e) {
  try {
    const d = JSON.parse(e.postData.contents)
    const ss = SpreadsheetApp.getActiveSpreadsheet()
    let sh = ss.getSheetByName(SHEET)
    if (!sh) {
      sh = ss.insertSheet(SHEET)
      sh.appendRow(['받은 때', '종류', '화면', '학년', '내용',
                    '보던 날짜', '위치', '창 크기', '브라우저'])
      sh.setFrozenRows(1)
    }
    sh.appendRow([
      new Date(), d.kind || '', d.screen || '', d.grade || '', d.text || '',
      d.when || '', d.loc || '', d.viewport || '', d.ua || ''
    ])
    if (NOTIFY) {
      MailApp.sendEmail(NOTIFY, '[달 관찰소] ' + (d.kind || '의견') + ' — ' + (d.screen || ''),
        (d.text || '') + '\n\n화면: ' + (d.screen || '') + ' / ' + (d.grade || '') + '학년' +
        '\n보던 날짜: ' + (d.when || '') + '\n위치: ' + (d.loc || ''))
    }
    return ContentService.createTextOutput('ok')
  } catch (err) {
    return ContentService.createTextOutput('error: ' + err)
  }
}

function doGet() { return ContentService.createTextOutput('달 관찰소 의견 받기 — 살아 있습니다') }
```

3. 위쪽 **저장(디스크 모양)** 을 누릅니다.

## 3. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴(유형 선택) → **웹 앱** 을 고릅니다.
3. 아래처럼 맞춥니다.
   - **실행 계정**: 나
   - **액세스 권한이 있는 사용자**: **모든 사용자** ← 이게 중요합니다
4. **배포** 를 누릅니다.
5. 처음이면 권한을 묻습니다 → **액세스 승인** → 내 계정 선택 →
   "이 앱은 확인되지 않았습니다" 화면이 나오면 **고급 → (안전하지 않음) 이동** 을 누릅니다.
   (내가 만든 내 스크립트라서 그렇습니다)
6. 마지막에 나오는 **웹 앱 URL** 을 복사합니다.
   `https://script.google.com/macros/s/AKfy.....d/exec` 처럼 생겼습니다.

## 4. 주소 넣기

`src/lib/feedbackStore.js` 파일의 첫 부분을 이렇게 고칩니다.

```javascript
export const ENDPOINT = 'https://script.google.com/macros/s/여기에_복사한_주소/exec'
```

깃허브에 올리면 몇 분 뒤 자동으로 반영됩니다.
**저에게 주소를 알려 주시면 제가 넣어 드리겠습니다.**

## 5. 확인

사이트에서 '의견 보내기' → 아무 내용이나 써서 보내 보세요.
스프레드시트에 줄이 하나 늘어나면 된 것입니다.

---

## 자주 겪는 일

| 증상 | 까닭 |
|---|---|
| 스프레드시트에 안 쌓임 | 3-3에서 **'모든 사용자'** 로 안 했을 가능성이 큽니다. 배포를 수정해 다시 하세요 |
| 스크립트를 고쳤는데 그대로임 | **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 를 해야 반영됩니다 |
| 메일 알림이 안 옴 | `NOTIFY` 에 메일 주소를 넣고 다시 배포했는지 확인하세요 |

## 다른 방법을 쓰고 싶다면

`feedbackStore.js` 의 `ENDPOINT` 는 **JSON 을 POST 로 받는 주소면 무엇이든** 됩니다.
파이어베이스 함수, 서버, Formspree 같은 서비스도 주소만 바꾸면 그대로 동작합니다.
보내는 자료의 모양은 이렇습니다.

```json
{
  "kind": "내용이 잘못됐어요",
  "screen": "오늘의 달",
  "grade": "4",
  "text": "사용자가 쓴 글",
  "when": "9. 4. 12:33",
  "loc": "서울 (북위 37.57° 동경 126.98°)",
  "viewport": "1440×900",
  "ua": "브라우저 정보"
}
```
